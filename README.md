# Integration Lab

Повноцінний сайт для консультацій та інформації для українців у Румунії.
Працює на одному сервері, дані спільні для всіх пристроїв і оновлюються в реальному часі.

## Що змінилося порівняно з одним HTML-файлом

| Було | Стало |
|---|---|
| Дані лише в браузері/платформі, кожен бачив своє | Сервер + база SQLite: усі пристрої бачать одне й те саме, живе оновлення (SSE) |
| Фасилітатор і учасник відрізнялися лише кнопкою | Три ролі з паролями, права перевіряє **сервер**: учасник не може відкрити панель чи викликати її API |
| Редагувати сторінки міг лише власник файлу | Фасилітатор редагує всі сторінки прямо на сайті (UK/RO/EN в одній формі), змінює порядок, видаляє. Учасник пропонує виправлення, фасилітатор схвалює |
| Одночасне редагування затирало чужі зміни | Версії записів: при конфлікті фасилітатор бачить попередження |
| Мало інформації | 17 статей у 9 категоріях + блок контактів + пошук, дата останньої перевірки на кожній статті |

## Ролі

- **Учасник**: приєднується за іменем, пароль не потрібен. Бере участь у заході, читає інформацію, пропонує правки.
- **Фасилітатор**: входить за логіном і паролем (посилання «Вхід для фасилітатора» внизу сторінки). Веде захід, редагує контент, розглядає пропозиції, бачить звіти.
- **Адміністратор**: усе, що фасилітатор, плюс створення/вимкнення акаунтів, журнал дій, резервна копія.

## Запуск

Потрібен **Node.js 22.13+**. Жодних npm-залежностей.

```bash
node server/index.js          # або: npm start
```

Відкрийте http://localhost:3000. Під час першого запуску консоль покаже **одноразовий код**.
Перейдіть «Вхід для фасилітатора», і сайт запропонує створити адміністратора (код + логін + пароль від 10 символів).
Далі в розділі «Фасилітатор → Команда» додайте решту фасилітаторів.

Забули пароль: `node server/cli.js reset-password <логін> <новий пароль>`.

## Публікація (щоб користувалися з різних пристроїв)

Потрібен хостинг, де працює Node.js і є **постійний диск** для папки `data` (інакше база зникне при перезапуску). Підійде VPS, Render, Railway, Fly.io тощо.

- Docker: `docker compose up -d --build` (база в томі `lab-data`).
- Без Docker: `DATA_DIR=/var/lib/lab TRUST_PROXY=1 node server/index.js` за nginx/Caddy (див. `Caddyfile.example`).
- **HTTPS обовʼязковий** для реального використання (паролі й сесії). Із `TRUST_PROXY=1` cookie автоматично стають Secure.
- Перевірка здоровʼя: `GET /api/health`.
- Резервна копія: Фасилітатор → Звіт → «Завантажити повну резервну копію» (лише адміністратор), або просто копіюйте `data/lab.sqlite`.

## Безпека (що вже зроблено)

Паролі: scrypt із сіллю. Сесії: випадкові токени в HttpOnly SameSite-cookie, у базі лише хеш. Обмеження спроб входу. Захист від CSRF (власний заголовок + перевірка Origin). CSP та інші заголовки. Усі поля перевіряються й обмежуються за довжиною на сервері; текст виводиться екрановано; посилання лише http(s). Чужі відповіді учасники бачать лише після «Показати», приватні відгуки бачать лише фасилітатори.

## Структура

```
server/index.js   HTTP-сервер, API, права доступу, SSE
server/auth.js    паролі, сесії, користувачі
server/db.js      схема SQLite
server/seed.js    стартовий контент (записується один раз; далі редагується на сайті)
server/cli.js     службові команди
public/           інтерфейс (index.html, app.js, i18n.js, themes.js, styles.css, sw.js)
test/e2e.test.js  автотести ролей і прав: npm test
```

## Важливо перед запуском для людей

- **Звірте факти в статтях.** Дати, суми та правила змінюються (особливо продовження тимчасового захисту до 4.03.2028 та правила для нових заявників). Кожна стаття має поле «Перевірено», яке оновлюється кнопкою «Позначити як перевірене сьогодні».
- Румунські та англійські тексти підготовлені мною. Бажано, щоб носій румунської переглянув їх.
- Тексти тем дебатів (`public/themes.js`) лишилися з вашого файлу без змін.
